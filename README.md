# PharmaTrain Libya

صمّم تطبيقًا احترافيًا متكاملًا لمنصة تعليم وتدريب طلاب الصيدلة في ليبيا، باسم مبدئي PharmaTrain Libya.

أريد تصميم UI/UX احترافي وحديث مستوحى من جودة وتجربة الاستخدام في تطبيقات Coursera وLinkedIn Learning، ولكن بهوية بصرية أصلية خاصة بالمنصة، وليس نسخة من أي تطبيق.

الهدف من التطبيق

منصة تربط طلاب الصيدلة بالصيدليات ومشرفي التدريب وشركات الأدوية، وتوفر:

التدريب العملي في الصيدليات.

الدورات التعليمية.

الفيديوهات التعليمية.

الاختبارات.

الحالات السريرية.

متابعة الحضور وساعات التدريب.

تقييم الطالب.

الشهادات الرقمية.

التواصل مع المشرف.

إدارة التدريب إلكترونيًا.
